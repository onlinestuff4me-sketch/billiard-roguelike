Table language · teaching it

One new thing at a time, and never two in the same breath

The system is only worth having if a player picks it up without being lectured. Six boards introduce the four families; after that, every new object gets a room of its own to be met in, with one banner and nothing else new on the table.

One new word per boardA board that introduces two nouns teaches neither. If a card needs a word the player has not met, that word is what the board is for.
The board holds only the thing it teachesEmpty felt around it. Clutter reads as difficulty, and a lesson has to be able to promise that the table contains its subject and nothing else.
Teach a distinction by showing bothYou cannot learn that a pad is not a pocket from a board with only a pad on it. Board 05 puts both gold things on one table deliberately.
Name it as it happensThe text that flies off the table uses the noun from the card, in the same seconds. Feedback is the second sighting of the word, and the second sighting is what makes it stick.
Say it once more, in the roomA thing met in a lesson is reinforced by one banner the first time it appears in a real room — and then never explained again.
Label the first sightingThe first time an object type appears in a run, a small chip sits beside it for three seconds. Once per type per run, then the table speaks for itself.

The first-sighting chip

Anchored beside the object in world space, three seconds, once per type per run. It names the thing and what it does, in the words the lesson used — so a player who skipped the tutorial still meets every noun exactly once, in context, at the moment it first matters.
